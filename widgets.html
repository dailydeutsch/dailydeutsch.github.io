The word of the day, on your home screen

Täglich Wort is a web app, and web apps cannot ship their own phone widgets. These two free workarounds use widget apps you install once. Both read the same daily feed as the app, so the widget always shows the same word, on the same day, at your level.

iPhone: Scriptable

  1. Install Scriptable from the App Store (free).
  2. Open this file, select all and copy it: TaeglichWort.js
  3. In Scriptable, tap + and paste. Name the script TaeglichWort.
  4. Long-press your home screen, add a Scriptable widget (medium looks best), then tap the widget to edit it: Script = TaeglichWort, Parameter = your level: 1, 2 or 3.
  5. Tap the widget any time to open the full word in the app.

The widget refreshes itself shortly after midnight and works offline from its last download.

Android: KWGT

KWGT can read the daily feed at https://dailydeutsch.github.io/today.json. In a KWGT text item, use Web Get formulas like these (change the level number 1 to 2 or 3 if you want another level):

Word:    $wg("https://dailydeutsch.github.io/today.json", json, .levels.1.entry.w)$
Article: $wg("https://dailydeutsch.github.io/today.json", json, .levels.1.entry.a)$
Meaning: $wg("https://dailydeutsch.github.io/today.json", json, .levels.1.entry.en)$
Example: $wg("https://dailydeutsch.github.io/today.json", json, .levels.1.entry.ex)$

Set the widget's update interval to daily, and give the widget a touch action that opens https://dailydeutsch.github.io/. The feed is regenerated every night (UTC), so the Android widget follows the UTC day.

For developers

Two open feeds, no key, CORS enabled by GitHub Pages: words.json (every word, grouped by level, with the day rule: day 1 was 21 November 2026, index cycles through each level's pool) and today.json (today's word per level).
